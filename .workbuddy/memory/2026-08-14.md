## 重建索引按钮无反应修复
- **现象**：点击重建索引无反应（用户已建好索引，点击应弹确认框）
- **诊断**：埋点 debug.log 显示 [toggle] 与 [dlg] open: 重建索引 均触发 → 弹窗打开了但用户看不到
- **根因**：_DialogShell 弹窗（Toplevel overrideredirect + transient）在无边框主窗下未置顶，被主窗挡在底层，无法交互 → 表现为"点了没反应"
- **修复**：_DialogShell 坐标钳制到屏幕内 + attributes("-topmost", True) + lift()，120ms 后归还层级；所有自绘弹窗（确认/输入）受益
- 验证：用户实测重建索引成功；debug.log [toggle]/[dlg] 链路完整
- 已 git commit（4d2af59）；重启后新实例运行正常
