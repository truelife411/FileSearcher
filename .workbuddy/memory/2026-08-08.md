## 压缩态下列宽拖不动修复

## 双击打开卡顿修复
- **用户反馈**：双击搜索结果（如视频文件）打开特别慢
- **排查**：实测 os.path.exists 0ms、os.startfile 72ms（异步）——程序侧调用本身不慢
- **根因**：os.startfile(ShellExecute) 在主线程调用时，关联程序响应慢（DDE 握手、大视频预读）会同步等待 ShellExecute 返回 → 播放器启动多久界面卡多久
- **修复**：open_with_default 改为后台线程执行 startfile，返回耗时 72ms→0.2ms，UI 永不卡顿；线程内 OSError 记录到 debug.log（后台线程无法弹窗）
- 已 git commit；重启后新实例 PID 83900
