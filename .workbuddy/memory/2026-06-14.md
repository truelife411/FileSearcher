## 搜索结果表格 Ctrl+C/X 支持资源管理器粘贴
- 问题：Ctrl+C/X 只是把路径作为纯文本放入剪贴板，Windows 资源管理器无法识别，导致文件夹中 Ctrl+V 无效
- 解决：用 `ctypes` 调用 Windows API，将选中文件以 `CF_HDROP` 格式写入剪贴板
- Ctrl+X 额外注册 `Preferred DropEffect`（=MOVE），让资源管理器执行移动而非复制
- `_copy_path` / `_cut_path` 改为调用新的 `_set_clipboard_hdrop()` 方法
- Git commit `6225141`
- 桌面 exe 已同步更新

## 删除、复制、剪切支持多行操作
- `_get_selected_paths()` 新方法：返回所有选中文件的路径列表
- `_copy_path` / `_cut_path`：支持多文件写入剪贴板，状态栏显示 "已复制 3 个文件"
- `_delete_file_recycle` / `_delete_file_permanent`：支持多文件删除，确认框显示数量
- `send_to_recycle_bin` / `permanent_delete`：改为接收 `list[str]`，用 `\0` 分隔多文件路径
- `_remove_from_results`：遍历移除所有选中文件
- 按住 Ctrl 或 Shift 可多选，右键菜单/快捷键均支持多文件操作
