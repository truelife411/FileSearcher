# 2026-06-30 工作日志

## 跨平台适配：支持 Linux (统信UOS)
- Git commit `1a2b004`
- 用 `sys.platform == "win32"` / `else` 条件分支，Windows 代码全部保留，新增 Linux 分支
- 具体改动：
  1. **打开文件**：Linux 用 `xdg-open` 替代 `os.startfile` / `explorer`
  2. **文件删除**：回收站用 `gio trash` / `trash-put`；彻底删除用 `os.remove` / `shutil.rmtree`
  3. **剪贴板**：Linux 降级为纯文本路径，用 `wl-copy` / `xclip` / `xsel` / Tkinter 兜底
  4. **DPI 感知**：只对 Windows 启用
  5. **窗口最大化**：Linux 用 `-zoomed` 属性替代 `state("zoomed")`
  6. **字体**：Linux 用 `"sans-serif"` 替代 `"Microsoft YaHei"`
  7. **索引忽略目录**：新增 Linux 虚拟文件系统：proc, sys, dev, run, lost+found, snap
  8. **SHFILEOPSTRUCTW** 仅在 Windows 路径中被调用
