# 2026-06-06

## 功能新增：FTS5 全文搜索 + 拼音搜索 + 重复文件检测

### FTS5 全文搜索
- 添加 `pypinyin` 依赖用于中文文件名转拼音
- 新增 `to_pinyin()` 工具函数
- 索引构建时同步写入 `files_fts` 虚拟表（三列：name, path, name_pinyin）
- 新增 `IndexEngine.search_fts()` 方法，支持中文分词 + 拼音搜索
- GUI 工具栏新增 "精确/模糊" 搜索模式切换下拉框
- 模糊模式使用 FTS5 MATCH 查询（含拼音），精确模式保持原 LIKE 查询
- `_load_more` 翻页也适配了模糊搜索

### 重复文件检测
- `files` 表新增 `hash` 列（TEXT, nullable）
- 两阶段检测：先按 size 分组找候选 → 再计算 MD5 哈希确认
- 新增方法：`find_duplicate_candidates()`, `compute_hashes_for_size()`, `get_duplicates()`, `_file_md5()`, `clear_hashes()`
- 新增 `_hash_column_exists()` 兼容旧索引
- GUI 新增 "查找重复文件" 按钮和 "退出重复视图" 按钮
- 重复结果分组显示，交替背景色区分组，显示可释放空间
- 后台线程扫描，不阻塞 UI

### 其他修复
- 修正 "大小" 列宽从 30→80，不再截断
- 旧索引缺少 hash 列时提示重建索引

### 依赖
- `pypinyin==0.55.0`（已安装到 managed venv）

## 性能优化：FTS/拼音改为后台延迟填充

- 索引阶段不再调用 `to_pinyin()` 和写入 FTS 表，扫描速度恢复如初
- 新增 `IndexEngine.populate_fts()` 方法，索引完成后后台线程批量填充
- `search_fts()` 在 FTS 为空时自动回退为 LIKE 精确搜索
- 重复文件哈希仅在用户点击"查找重复文件"时触发，确认对话框提示耗时
